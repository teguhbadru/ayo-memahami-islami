# Ayo Memahami! Edisi Islami

Aplikasi belajar memahami bacaan bertahap untuk anak usia 6–9 tahun, berdasarkan modul yang disediakan.

## Fitur
- 5 tingkat pemahaman dan 15 cerita Islami
- Latihan pilihan ganda, benar/salah, dan esai
- Kata baru, nilai kehidupan, refleksi, dan mutiara hikmah
- Mode orang tua/guru dengan kunci jawaban
- Pemantauan skor dan sertifikat yang dapat dicetak
- Kemajuan tersimpan di localStorage browser

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

## Build produksi

```bash
npm run build
npm run preview
```

Hubungkan repository ini ke Vercel untuk deployment otomatis.
