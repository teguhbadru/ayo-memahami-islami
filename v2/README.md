# Ruang Cendekia 2.0

Standalone Vite + React app (folder /v2), based on the visual reference provided by the owner. The former /src app and its Vercel production project are separate and remain unchanged.

Features: home, five levels / 100 stories (copied from the pre-existing library), search, favourites, reading view with adjustable font, all oral questions with optional parent-only response notes, correct-answer guidance, real-life scenarios and kindness tasks, completion progress in localStorage, browser back/forward using URL hash.

The new v2 app is a beta and does not charge for access. Never imply premium checkout is active. The illustration used for story 1.1 is a newly illustrated SVG cover; other 99 stories currently use decorative theme covers. Commission bespoke painterly illustrations for all stories before commercial publishing.

Deployment: New Vercel project with Root Directory = v2, framework Vite, Build Command npm run build, Output Directory dist. Existing project still points to root and is unaffected by v2 source.

Content: Five data files and existing 15 stories are copied from old content as independent blobs. Do not alter the originals without editorial review.
